# AWS DeepComposer

## Purpose

USB keyboard plus learning service teaching GenAI through music generation. Aimed at developers building intuition for foundation models in a low-stakes domain.

## Trade-offs

- Deprecated. AWS retired DeepComposer; included in the catalogue
  only because legacy architectures may reference it. New work
  should not target it under any pretext.
- The educational replacement is PartyRock for prompt-engineering
  exploration and SageMaker Studio Lab for ML fundamentals.
  Both are better matched to current learner needs than a
  retired hardware-plus-cloud combo.
- Existing DeepComposer hardware has no AWS-side service to
  drive — treat it as a curiosity, not infrastructure.
