# Amazon WorkDocs

## Purpose

Managed enterprise document storage and sharing. New customer sign-ups and account upgrades are no longer available; AWS publishes migration guidance for existing tenants.

## Trade-offs

- End-of-life service. New customer sign-ups are closed; existing
  tenants are on a migration timeline. Catalogue entry is for
  legacy reference, not for new selection.
- Migration targets are Microsoft 365 / Google Workspace /
  Dropbox / Box. AWS's recommended path varies by region and
  use case; the published guidance is the starting point.
- Any architecture still showing WorkDocs is a sign of
  staleness. Treat as a hard-deprecated dependency.
