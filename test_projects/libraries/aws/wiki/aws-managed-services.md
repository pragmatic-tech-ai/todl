# AWS Managed Services

## Purpose

Outsourced ongoing management of an AWS estate. Automates change requests, monitoring, patching, security, and backup, with full-lifecycle support for hosted infrastructure.

## Trade-offs

- Outsourced ops, billed substantially. AMS makes sense when
  the customer needs production AWS operations but has no
  in-house platform team. The cost is a meaningful percentage
  of the underlying AWS spend.
- Change-request workflow constrains agility. AMS standardises
  on RFC-style change windows; teams used to push-button
  deploys find this slows their iteration speed materially.
- vs. Rackspace Technology / DXC / Deloitte / large SI partners:
  AWS Managed Services is a specific AWS-provided offering;
  competing SI / MSP partners deliver similar outcomes with
  different procurement and SLA models. Evaluate by partner
  relationship, not just by feature parity.
