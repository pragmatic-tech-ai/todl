# Amazon WorkSpaces Thin Client

## Purpose

Low-cost thin-client device for the AWS End User Computing portfolio. Connects two monitors and USB peripherals; designed as the access endpoint for WorkSpaces.

## Trade-offs

- Hardware purchase. Buying thin clients commits the org to a
  device refresh cycle and a fleet-management process. Cheaper
  than full PCs only at scale and with a real lifecycle plan.
- vs. Stratodesk / IGEL / Dell Wyse: dedicated thin-client
  vendors lead on management software and OS hardening. AWS
  Thin Client wins on price for AWS-connected fleets and on
  integration with WorkSpaces.
- The endpoint is half the story. Network reliability at the
  client site dominates the user experience — flaky office
  Wi-Fi negates the appliance's advantages.
