# AWS Elemental Appliances and Software

## Purpose

On-premises video processing and delivery — Elemental Live, Server, Conductor, and Link. Connects on-prem encode pipelines to cloud-based delivery.

## Trade-offs

- Hardware + software products with capex pricing — fundamentally
  different from cloud media services. Broadcasters and venues
  with on-site encode requirements live here; cloud-native
  workflows do not.
- Elemental Live and Server compete with traditional broadcast
  encoders (Harmonic, Ateme, AJA). Pick on encoder feature
  parity, codec roadmap, and contribution-link integration —
  not on AWS-cloud convenience, which is downstream.
- Elemental Link is the lighter offering — a low-cost
  contribution encoder feeding cloud MediaLive. Useful as the
  on-ramp from on-site cameras into the AWS media stack.
