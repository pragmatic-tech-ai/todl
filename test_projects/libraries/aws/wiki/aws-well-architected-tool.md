# AWS Well-Architected Tool

## Purpose

Workload-review tool aligning architectures with the Well-Architected Framework's six pillars (operational excellence, security, reliability, performance efficiency, cost optimisation, sustainability).

## Trade-offs

- Self-assessment tool, not a continuous validator. Teams that
  complete a review and don't repeat it get a one-time
  snapshot; the value is in the discipline of returning to it
  quarterly or per-major-change.
- Quality of output reflects quality of input. Honest answers
  produce useful findings; check-the-box answers produce
  spreadsheet reports nobody acts on. The cultural lift
  outweighs the tooling.
- vs. AWS Partner-led reviews: AWS Solution Architect-led
  Well-Architected reviews carry weight that self-service
  reviews don't, and unlock the partner-funding incentive
  programmes. Use the tool to maintain between formal reviews.
