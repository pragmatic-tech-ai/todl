# Microsoft 365 Backup

## Purpose

Microsoft 365 Backup provides faster, point-in-time backup and restore for Exchange Online, SharePoint, and OneDrive content, filling the gap between the native recycle-bin and third-party backup products. It is operated directly within the Microsoft 365 admin centre with no external infrastructure, and is designed for near-real-time recovery (restore points as recent as 10 seconds for SharePoint) rather than long-term archival — which is handled by Microsoft 365 Archive and Purview retention policies.
