# Azure Translator

## Purpose

Azure Translator is a cloud-based neural machine translation service within Foundry Tools supporting more than 100 languages and dialects including at-risk and endangered languages, with features spanning real-time text translation, asynchronous batch document translation, synchronous single-file document translation, and custom translation model training through Custom Translator. It underpins translation features across Microsoft products and is used by thousands of third-party applications, with container-based deployment available for offline and compliance-constrained scenarios. A preview API introduces LLM-assisted adaptive translation capable of learning from in-domain examples at query time.
