# Microsoft Intune

## Purpose

Microsoft Intune is the cloud-based unified endpoint management service in Microsoft 365 that enforces security policies, deploys applications, and manages compliance across Windows, macOS, iOS, and Android devices — both corporate-owned and personal (BYOD). It replaces on-premises SCCM and MDM infrastructure for organisations moving to a cloud-first device management model, and integrates with Microsoft Entra ID for conditional access policies that gate application access based on device compliance state.
