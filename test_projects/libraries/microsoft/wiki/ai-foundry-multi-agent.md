# AI Foundry Multi-Agent

## Purpose

AI Foundry Multi-Agent is the orchestration capability within Microsoft Foundry that enables multiple specialised agents to collaborate on a task by routing subtasks, sharing context, and aggregating results under a coordinating orchestrator. It extends Foundry Agent Service to multi-agent topologies — fan-out, sequential chains, hierarchical delegation — without requiring custom inter-agent communication infrastructure.
