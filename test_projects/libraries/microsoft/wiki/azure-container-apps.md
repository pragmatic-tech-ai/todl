# Azure Container Apps

## Purpose

Serverless container service built on Kubernetes, KEDA, and Dapr. Supports event-driven architectures, automatic scale-to-zero, and revision-based rollout without exposing the underlying Kubernetes API. Sits between Functions and AKS in the container-platform spectrum.
