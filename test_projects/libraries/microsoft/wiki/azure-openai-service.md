# Azure OpenAI Service

## Purpose

Managed service providing REST API access to OpenAI's GPT, embeddings, DALL-E, and Whisper models hosted in Azure. Adds enterprise controls — private networking, content filters, customer-managed keys, role-based access — so OpenAI models run under Azure compliance boundaries.
