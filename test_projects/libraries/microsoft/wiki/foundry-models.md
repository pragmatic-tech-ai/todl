# Foundry Models

## Purpose

Foundry Models sold directly by Azure is the curated model catalog within Microsoft Foundry providing access to all Azure OpenAI models — including GPT-5.x, o-series reasoning models, GPT-4o, audio, image-generation, video-generation, and embedding models — alongside selected third-party models from providers such as DeepSeek, Meta, Mistral AI, Cohere, and xAI, all billed through the Azure subscription and covered by Azure SLAs. Deployment options include Global Standard, Global Provisioned Managed, Global Batch, Data Zone, and regional Standard and Provisioned tiers to balance cost, latency, and data-residency requirements. Azure Government availability is documented separately, with some models and deployment types restricted in sovereign regions.
