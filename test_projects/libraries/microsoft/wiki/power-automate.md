# Power Automate

## Purpose

Power Automate is the workflow automation and robotic process automation service within Microsoft Power Platform. It connects 900+ applications and services through a no-code/low-code designer to synchronise files, trigger alerts, automate approvals, and execute multi-step business processes. It extends the earlier Microsoft Flow product and replaces manual hand-offs between systems, providing both cloud flows (event-triggered) and desktop flows (RPA for legacy UI automation).
