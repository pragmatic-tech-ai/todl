# Azure Data Share

## Purpose

Azure Data Share is the managed data-sharing service that allows organisations to send snapshots of Azure data assets (Blob Storage, Data Lake, SQL Database, Synapse) to external recipients across Azure tenants, with no file transfer infrastructure or custom API integration required. The share provider controls what data is shared and how often it refreshes; recipients receive it directly into their own Azure storage. It replaces ad-hoc file-export workflows and cross-organisation SFTP pipelines for recurring data exchange between business partners or subsidiaries.
