# Azure SQL

## Purpose

Azure SQL is the family of fully managed, intelligent relational database services built on the SQL Server engine, encompassing Azure SQL Database (serverless and Hyperscale), Azure SQL Managed Instance, and SQL Server on Azure VMs. The family provides near-complete SQL Server compatibility with built-in AI query tuning, automatic backups, and geo-replication, serving as the primary migration target for on-premises SQL Server workloads moving to Azure.
