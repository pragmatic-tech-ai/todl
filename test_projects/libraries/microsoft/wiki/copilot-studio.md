# Copilot Studio

## Purpose

Copilot Studio is the low-code authoring platform for building AI-driven agents and conversational flows on the Microsoft Power Platform. It enables teams to design multi-step reasoning agents that connect to data sources, call actions, escalate to human agents, and publish to Teams, web chat, and M365 Copilot channels. It extends the earlier Power Virtual Agents product with generative AI capabilities and integration with Azure OpenAI and the Foundry model catalog.
