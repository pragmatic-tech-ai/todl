# Copilot Agent

## Purpose

A Copilot Agent is the runtime unit of autonomous AI capability authored in Copilot Studio or Microsoft 365 Copilot. It represents a deployed, configured agent that can be invoked by users or orchestrators to perform multi-step tasks — retrieving data, calling APIs, filling forms, routing work — within the Power Platform and M365 ecosystem. Copilot Agents sit at the boundary between orchestration logic and the underlying LLM and tool layers.
