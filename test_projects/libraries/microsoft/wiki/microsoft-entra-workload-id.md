# Microsoft Entra Workload ID

## Purpose

Microsoft Entra Workload ID manages identities for non-human workloads — applications, services, scripts, and containers — providing application registrations, managed identities, and workload identity federation so that code can authenticate to Azure and Microsoft APIs without storing long-lived secrets. It consolidates what was previously split across App Registrations, Service Principals, and Managed Identities into a governed workload identity plane, and applies conditional access and risk detection to non-human credentials in the same policy framework as human identities.
