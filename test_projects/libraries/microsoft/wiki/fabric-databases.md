# Fabric Databases

## Purpose

Fabric Databases is the transactional database workload within Microsoft Fabric, providing SQL Database and mirroring capabilities that bring operational relational and document data into the Fabric estate. SQL Database in Fabric is a cloud-native relational store (based on the Azure SQL Database engine) hosted within a Fabric workspace, while database mirroring replicates data from external sources such as Azure SQL Database, Cosmos DB, and Snowflake into OneLake for analytical consumption without a separate ETL pipeline.
