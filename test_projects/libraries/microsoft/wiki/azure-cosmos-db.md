# Azure Cosmos DB

## Purpose

Fully managed NoSQL and vector database with single-digit-millisecond response times, automatic and instant scalability, and turnkey multi-region writes. Backs operational and AI workloads that need globally distributed, low-latency document, key-value, graph, or column data.
