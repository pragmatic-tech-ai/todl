# Microsoft Entra Agent ID

## Purpose

Microsoft Entra Agent ID provides identity lifecycle management for AI agents and non-human workloads, assigning each agent a unique, auditable identity within the Microsoft Entra directory so that agents can be governed with the same conditional access, entitlement, and risk policies applied to human identities. It addresses the emerging challenge of agentic AI systems that act on behalf of users or autonomously — ensuring every action taken by an agent is traceable to a specific credential and can be revoked through standard identity governance controls.
