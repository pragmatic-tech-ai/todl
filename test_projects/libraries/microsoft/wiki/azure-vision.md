# Azure Vision

## Purpose

Azure Vision is the computer vision service within Foundry Tools providing access to algorithms for processing images and extracting visual information, encompassing facial detection and recognition (via the Face service), legacy Image Analysis for object detection, auto-captioning, and feature extraction from images, and legacy OCR for printed and handwritten text extraction. The Image Analysis 4.0 API has been deprecated and is scheduled for retirement on September 25, 2028, with migration paths to newer endpoints available; new architectures should target current-generation Vision capabilities.
