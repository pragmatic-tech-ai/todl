# Microsoft Forms

## Purpose

Microsoft Forms is the lightweight survey, quiz, and poll authoring tool in Microsoft 365, enabling any user to create data-collection forms that can be shared with internal colleagues or external respondents via link or embed. Responses aggregate in real-time charts within Forms and can be exported to Excel or Power BI for further analysis, replacing standalone form tools for typical employee engagement surveys, feedback collection, and educational quizzes.
