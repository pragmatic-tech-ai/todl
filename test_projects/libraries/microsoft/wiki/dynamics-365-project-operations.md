# Dynamics 365 Project Operations

## Purpose

Dynamics 365 Project Operations is the project-centric ERP application in Dynamics 365, combining project planning, resource scheduling, time and expense tracking, project billing, and financial accounting for professional services organisations and project-driven businesses. It merges the former Dynamics 365 Project Service Automation with project accounting from Dynamics 365 Finance, providing a single application from sales deal to project invoicing without data synchronisation between separate CRM and ERP systems.
