# Dynamics 365 Remote Assist

## Purpose

Dynamics 365 Remote Assist is the mixed-reality collaboration application for field technicians and frontline workers, enabling an on-site worker wearing HoloLens or using a mobile device to share their live view with a remote expert via Teams video call and receive annotated guidance overlaid on the physical environment. It replaces phone-described instructions and truck-roll escalations for complex equipment repairs by letting a specialist guide an on-site worker in real time using spatial annotations without both parties needing to be physically present.
