# Microsoft Entra Internet Access

## Purpose

Microsoft Entra Internet Access is the Secure Web Gateway component of Microsoft's Security Service Edge solution, routing internet-bound traffic from managed devices and branch offices through Microsoft's global network edge to enforce identity-aware web filtering, threat protection, and universal conditional access policies. It extends the Entra conditional access model beyond SaaS applications to any internet destination, replacing standalone proxy and firewall appliances for organisations adopting a Zero Trust network architecture.
