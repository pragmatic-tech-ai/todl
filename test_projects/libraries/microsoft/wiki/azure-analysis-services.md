# Azure Analysis Services

## Purpose

Enterprise-grade in-memory tabular semantic-modeling engine in the cloud. Provides the analytics layer behind Power BI and other reporting tools, with row-level security, perspectives, and partitioned models. Predates Power BI Premium and Fabric semantic models but remains in use for lift-and-shift SSAS workloads.
