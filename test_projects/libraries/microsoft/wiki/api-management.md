# API Management

## Purpose

Hybrid, multicloud API platform that fronts disparate backend services with a unified gateway, developer portal, and policy engine. Publishes APIs to internal and external consumers, applies cross-cutting policies (auth, throttling, transformation, caching), and decouples API consumers from the implementing services across cloud and on-premises environments.
