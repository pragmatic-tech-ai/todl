# Microsoft Fabric

## Purpose

Microsoft Fabric is the unified, AI-powered SaaS analytics platform that consolidates data engineering, data integration, data warehousing, real-time analytics, data science, and business intelligence on a single OneLake storage foundation. It replaces the need to integrate Azure Synapse Analytics, Azure Data Factory, Power BI, and separate data lake tooling as independent services, providing a single governance boundary, billing model, and compute-agnostic workspace for all analytical workloads.
