# Microsoft Entra ID Protection

## Purpose

Microsoft Entra ID Protection is the risk-based identity threat detection service in Microsoft Entra ID that continuously evaluates sign-in signals — atypical travel, leaked credentials, anomalous token usage — and assigns risk scores that feed into conditional access policies to block, challenge with MFA, or remediate high-risk identities automatically. It replaces manual log review and reactive account lockout with continuous, signal-driven identity risk management integrated into the authentication flow itself.
