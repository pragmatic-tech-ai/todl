# Fabric Data Warehouse

## Purpose

Fabric Data Warehouse is the T-SQL-based warehouse workload within Microsoft Fabric, providing a fully managed, serverless analytical database that stores its data in Delta Parquet format on OneLake rather than in proprietary warehouse storage. It enables SQL-fluent analysts to build structured schemas and query OneLake data with familiar SSMS or query editor tooling while sharing the same data files with Spark-based Fabric workloads — eliminating the copy required by traditional separation of data lake and SQL warehouse layers.
