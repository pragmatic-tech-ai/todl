# OneDrive

## Purpose

OneDrive is the personal cloud file storage and sync service in Microsoft 365, providing each licensed user a private file store that synchronises across devices and integrates with SharePoint Online for team-scoped sharing. It replaces network file shares and FTP drop-zones as the standard personal storage layer in Microsoft 365 organisations, and acts as the underlying storage mechanism for files attached to Teams chats and user profile documents.
