# Microsoft Dataverse

## Purpose

Microsoft Dataverse is the secure, scalable, low-code cloud data platform that underlies Power Platform applications and Dynamics 365. It stores and manages business data in a rich, schema-enforced environment with a strong type system, business rules, row-level security, auditing, and built-in integration with both M365 and Azure. Dataverse replaces earlier Common Data Service (CDS) and serves as the operational database for model-driven Power Apps, Copilot Studio agents, and Dynamics 365 workloads.
