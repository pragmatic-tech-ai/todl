# Fabric Data Science

## Purpose

Fabric Data Science is the ML experimentation and model lifecycle workload within Microsoft Fabric, providing notebooks, MLflow experiment tracking, model registries, and end-to-end ML run management on top of Fabric's shared Spark and OneLake infrastructure. It is the Fabric-native alternative to Azure Machine Learning for teams that manage data engineering and ML work within a single Fabric workspace boundary, eliminating the need to move data out of OneLake for training or batch inference.
