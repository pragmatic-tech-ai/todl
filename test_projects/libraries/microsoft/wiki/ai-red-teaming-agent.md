# AI Red Teaming Agent

## Purpose

The AI Red Teaming Agent is an automated adversarial probing service within the Azure Foundry Agent Service that discovers safety risks in generative AI systems before they reach production. It orchestrates systematic attack campaigns against model and agent endpoints, evaluates each attack-response pair against risk metrics such as Attack Success Rate, and produces scorecards covering content safety, prohibited actions, sensitive data leakage, and task adherence failures. It operates on top of Microsoft's open-source PyRIT framework and Foundry's Risk and Safety Evaluations, reducing the manual effort required to establish a red-team baseline during AI deployment cycles.
