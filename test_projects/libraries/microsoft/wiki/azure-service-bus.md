# Azure Service Bus

## Purpose

Azure Service Bus is the enterprise message broker providing durable queues and publish-subscribe topics for decoupling application components. It guarantees at-least-once and optionally exactly-once delivery semantics, dead-lettering, sessions for FIFO ordering, and scheduled message delivery. Service Bus replaces on-premises MSMQ and IBM MQ patterns for cloud-native and hybrid messaging between microservices, workflows, and backend systems.
