# Dynamics 365 Commerce

## Purpose

Dynamics 365 Commerce is the unified omnichannel retail platform in Dynamics 365, combining point-of-sale, e-commerce storefront, merchandise management, and loyalty program capabilities into a single system backed by Dataverse and the Azure cloud. It replaces standalone POS systems and separately managed e-commerce platforms for retailers seeking a single source of truth for inventory, pricing, and customer data across physical stores, web, and mobile channels.
