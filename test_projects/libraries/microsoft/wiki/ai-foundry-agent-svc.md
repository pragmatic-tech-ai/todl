# Foundry Agent Service

## Purpose

Foundry Agent Service is the managed Azure service for building, deploying, and orchestrating AI agents within the Microsoft Foundry platform. It provides the agent runtime — session management, tool invocation, memory, and multi-agent coordination — that backs agents built with the Azure AI Agent SDK. It replaces custom orchestration code that teams previously assembled from individual LLM and tools API calls.
