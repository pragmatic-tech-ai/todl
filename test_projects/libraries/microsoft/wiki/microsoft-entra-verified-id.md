# Microsoft Entra Verified ID

## Purpose

Microsoft Entra Verified ID implements the W3C Verifiable Credentials standard, allowing organisations to issue tamper-evident digital credentials (for employee badges, academic certificates, age verification, or professional licences) that holders store in a digital wallet and present to verifying parties without the issuer needing to be consulted at verification time. It replaces federated-identity-check patterns that require real-time calls to an authoritative directory, enabling privacy-preserving, decentralised credential exchange between organisations.
