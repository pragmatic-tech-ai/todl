# Azure Synapse Analytics

## Purpose

Limitless analytics service that unifies big-data analytics and data warehousing with a cloud-native, decoupled compute-and-storage architecture. Dedicated SQL pools, serverless SQL, and Spark pools share a single workspace; superseded for new workloads by Microsoft Fabric.
