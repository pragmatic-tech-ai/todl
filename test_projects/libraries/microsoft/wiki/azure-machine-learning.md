# Azure Machine Learning

## Purpose

Azure Machine Learning is a cloud service that manages the end-to-end machine learning lifecycle, providing data scientists, ML engineers, and application developers with collaborative tooling for training, deploying, and operating models using frameworks such as PyTorch, TensorFlow, and scikit-learn. It includes managed Jupyter Notebooks, the no-code designer for pipeline authoring, AutoML for automated model selection, hyperparameter sweeps, and managed inferencing endpoints for real-time and batch scoring under MLOps governance. Data is processed and stored within the deployment region, supporting data-residency requirements.
