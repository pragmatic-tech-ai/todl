# Microsoft Bookings

## Purpose

Microsoft Bookings is the scheduling and appointment-management service in Microsoft 365 that allows organisations to publish booking pages where external customers, clients, or patients can self-schedule meetings against staff availability. It integrates with Exchange Online calendars to prevent double-booking and sends automated confirmation and reminder emails, replacing manual back-and-forth scheduling for service businesses, healthcare practices, and support teams.
