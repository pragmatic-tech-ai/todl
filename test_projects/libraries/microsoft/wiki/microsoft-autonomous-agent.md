# Microsoft Autonomous Agent

## Purpose

Microsoft Autonomous Agent is a runtime capability on the Power Platform that enables agents to operate without continuous human prompting — observing events, reasoning over goals, and taking multi-step actions autonomously across business systems. It extends the Copilot Agent model toward long-running, proactive process execution and is the Power Platform's answer to agentic AI patterns that require planning, tool use, and memory across multiple turns.
