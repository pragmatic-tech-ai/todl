# Azure OpenAI GPT-4o

## Purpose

Azure OpenAI GPT-4o is the deployment of OpenAI's GPT-4o multimodal language model on Azure infrastructure, providing enterprise-grade access with private networking, content filtering, customer-managed keys, and role-based access control. GPT-4o processes text, images, and audio in a single model, enabling applications that combine natural-language reasoning, vision understanding, and structured output generation without separate specialised models.
