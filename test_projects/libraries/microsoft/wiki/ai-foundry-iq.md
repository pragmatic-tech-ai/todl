# Foundry IQ

## Purpose

Foundry IQ is an intelligence layer within Microsoft Foundry that unifies business semantics — connecting structured data, model outputs, and enterprise knowledge — so agents and applications can reason over a live, consistent view of the business. It sits between raw data and generative AI reasoning to ensure that model-grounded responses reflect current operational state rather than stale context.
