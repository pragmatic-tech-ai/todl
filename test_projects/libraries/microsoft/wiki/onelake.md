# OneLake

## Purpose

OneLake is the single, unified, logical data lake for the entire Microsoft Fabric tenant, automatically provisioned with every Fabric workspace and requiring no infrastructure to manage. All Fabric workloads — lakehouses, warehouses, notebooks, KQL databases — store their data in OneLake in open Delta-Parquet format, enabling any compute engine to read the same data without copying it. Shortcuts extend OneLake to reference data stored in external sources such as ADLS Gen2, S3, and Google Cloud Storage.
