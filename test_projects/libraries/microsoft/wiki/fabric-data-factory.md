# Fabric Data Factory

## Purpose

Fabric Data Factory is the data integration and pipeline orchestration workload within Microsoft Fabric, providing drag-and-drop data pipelines and dataflows (Power Query-based transformations) for ingesting and moving data into OneLake from hundreds of connectors. It is the Fabric-native evolution of Azure Data Factory, co-located with the Fabric workspace so pipelines, lakehouses, and warehouses share governance and monitoring without cross-service plumbing.
