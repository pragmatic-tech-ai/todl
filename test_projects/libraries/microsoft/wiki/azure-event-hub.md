# Azure Event Hub

## Purpose

Azure Event Hubs is the big-data streaming platform and event ingestion service that receives and processes millions of events per second from devices, applications, and services. It provides a time-ordered, partitioned log with Kafka protocol compatibility and acts as the front door for telemetry, click-stream, and IoT data entering analytics pipelines. Event Hubs decouples event producers from consumers through durable retention and consumer group isolation.
