# SharePoint Embedded

## Purpose

SharePoint Embedded is a developer-facing API model that lets independent software vendors and enterprise developers store, manage, and share application content in SharePoint Online containers without exposing a traditional SharePoint site. It extends the SharePoint document-management platform into custom applications, enabling ISVs to build document-centric products that sit on the same compliance, governance, and content-intelligence foundation as M365 without building storage infrastructure.
