# Azure Speech

## Purpose

Azure Speech is the speech AI service within Foundry Tools that provides speech-to-text, text-to-speech, speech translation, and live AI voice conversation capabilities through a Microsoft Foundry resource. It supports real-time, fast, and batch transcription modes; neural text-to-speech voices with SSML customization; custom voice creation; and the Voice Live feature for low-latency conversational AI. Container-based deployment is available for on-premises and edge scenarios, and the service is accessible in Azure Government and the Azure operated by 21Vianet sovereign cloud.
