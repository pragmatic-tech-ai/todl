# Azure AI Immersive Reader

## Purpose

Azure AI Immersive Reader is a cloud-based accessibility and reading-comprehension service within Foundry Tools that applies proven pedagogical techniques to help new readers, language learners, and people with conditions such as dyslexia engage with text. Its capabilities include content isolation, picture dictionaries, parts-of-speech highlighting, text-to-speech narration, real-time translation across supported languages, and syllabification; the same underlying technology powers the reading features in Microsoft Word and OneNote. It is consumed as an SDK-backed web component that can be embedded into any application.
