# M365 Copilot

## Purpose

Microsoft 365 Copilot is the AI-powered productivity assistant embedded across the Microsoft 365 application suite — Word, Excel, PowerPoint, Outlook, and Teams. It combines large language models with real-time access to the user's M365 data (email, calendar, documents, chat) via Microsoft Graph to draft, summarise, analyse, and automate work within existing applications. It replaces discrete task-by-task automation with conversational, context-aware assistance at the point of authoring.
