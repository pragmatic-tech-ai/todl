# Azure AI Search

## Purpose

Azure AI Search is a managed cloud search and retrieval service that combines full-text, vector, hybrid, and semantic re-ranking capabilities to support retrieval-augmented generation (RAG) patterns for generative AI applications. It replaces the earlier Azure Cognitive Search brand and adds native integration with Azure OpenAI, Foundry embeddings, and index projection pipelines. The service is the primary vector store and retrieval layer for enterprise AI applications built on Azure.
