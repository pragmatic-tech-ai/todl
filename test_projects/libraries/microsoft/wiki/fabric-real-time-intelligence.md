# Fabric Real-Time Intelligence

## Purpose

Fabric Real-Time Intelligence is the streaming and time-series analytics workload within Microsoft Fabric, providing an event-streaming ingestion pipeline, KQL (Kusto Query Language) databases, and real-time dashboards for monitoring IoT telemetry, application logs, and business events. It is the Fabric-native successor to Azure Data Explorer and Azure Stream Analytics for teams that want real-time analytics co-located with their batch analytics and OneLake storage inside a single Fabric workspace governance boundary.
