# Azure Health Data Services

## Purpose

Suite of healthcare-focused APIs — FHIR service, DICOM service, MedTech service — for ingesting, persisting, and exchanging protected health information under HIPAA-compliant operations. Successor to Azure API for FHIR for new healthcare integrations.
