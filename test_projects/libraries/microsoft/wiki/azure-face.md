# Azure Face

## Purpose

Azure Face is an AI service within Foundry Tools that provides facial detection, recognition, and analysis algorithms for scenarios including identity verification, touchless access control, liveness detection, and face redaction in images. Access to the full recognition capability set is restricted to Microsoft-managed customers and partners through an approved intake process, reflecting Responsible AI principles around biometric data. The liveness detection feature has achieved iBeta Level 1 and Level 2 PAD test certification under ISO/IEC 30107-3.
