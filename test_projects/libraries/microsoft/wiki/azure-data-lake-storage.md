# Azure Data Lake Storage

## Purpose

Hierarchical-namespace storage built on Azure Blob Storage and optimized for big-data analytics. Provides POSIX-style ACLs and integrates with Synapse, Databricks, and HDInsight as the canonical landing zone for Azure data lake architectures.
