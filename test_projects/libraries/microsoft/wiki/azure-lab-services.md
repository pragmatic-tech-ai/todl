# Azure Lab Services

## Purpose

Azure Lab Services is the managed lab environment service for creating and distributing pre-configured virtual machines to students, trainees, or development teams at scale, without requiring participants to have Azure subscriptions or configure VMs themselves. An instructor or admin defines a lab template VM with the required software, sets usage quotas and schedules, and Azure Lab Services handles provisioning, shutdown automation, and usage cost tracking — replacing locally managed lab servers and per-user VM allocation for training, education, and hackathon scenarios.
