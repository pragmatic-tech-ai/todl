# Azure Backup

## Purpose

Managed backup service for Azure VMs, SQL, file shares, and on-premises workloads. Provides immutable vaults, soft-delete, and long-term retention so recovery from accidental deletion, ransomware, or regional failure does not depend on workload-specific backup tooling.
