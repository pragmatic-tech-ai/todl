# Azure AI Content Safety

## Purpose

Azure AI Content Safety is a managed Azure service that detects harmful content — spanning hate, violence, sexual content, and self-harm — in both text and images, serving as a moderation layer for applications built on user-generated or AI-generated content. Beyond categorical flagging it provides Prompt Shields for jailbreak detection, groundedness detection, and protected material detection, and exposes a Content Safety Studio for no-code evaluation. The service carries FedRAMP Moderate, HIPAA BAA, and Cloud Security Alliance STAR compliance and is available in both commercial Azure regions and selected US Government regions.
