# App Service

## Purpose

Fully managed PaaS for building, deploying, and scaling web apps and HTTP APIs in .NET, Java, Node.js, Python, and PHP. Provides autoscaling, deployment slots, built-in auth, and managed runtime hosts so teams ship code without operating the underlying VMs or load balancers.
