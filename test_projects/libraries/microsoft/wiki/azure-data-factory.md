# Azure Data Factory

## Purpose

Hybrid data-integration service for orchestrating and automating ETL/ELT pipelines across 90+ built-in source and sink connectors. Provides mapping data flows for transformation and SSIS lift-and-shift for legacy packages, sitting between source systems and Azure analytics stores.
