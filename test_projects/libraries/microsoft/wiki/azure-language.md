# Azure Language

## Purpose

Azure Language is a cloud-based NLP service within Foundry Tools that provides text understanding and analysis capabilities including PII detection, named entity recognition, text analytics for health, language detection, sentiment analysis, summarization, question answering, and conversational language understanding. Its capabilities are also surfaced as MCP server tools through the Azure Language Tool Catalog, enabling AI agents to call language features without bespoke integration code. A PII anonymization feature using synthetic replacement is currently in preview.
