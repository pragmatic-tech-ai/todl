# Microsoft Graph

## Purpose

Microsoft Graph is the unified REST API gateway for all Microsoft 365 services, exposing data about users, mail, calendar, files, teams, identity, and security through a single endpoint at `graph.microsoft.com`. It replaces the earlier per-service APIs (Exchange REST, SharePoint REST, Azure AD Graph) with a consistent, permission-scoped surface that applications and agents use to read and write M365 data without integrating directly with each underlying service.
