# Azure Data Manager for Agriculture

## Purpose

Industry data platform that ingests, normalizes, and unifies agricultural data — farm-machinery telemetry, weather, satellite imagery, soil sensors — and exposes it through standard APIs. Lets AgTech applications operate on a coherent farm-data graph instead of vendor-specific feeds.
