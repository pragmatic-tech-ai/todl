# Azure Data Manager for Energy

## Purpose

Azure Data Manager for Energy is the managed cloud service implementing the OSDU (Open Subsurface Data Universe) data platform standard for the energy industry, providing a shared subsurface data repository for seismic, well log, drilling, and production data that is accessible via open APIs to interpretation and engineering tools. It removes the operational complexity of running OSDU on custom infrastructure, enabling oil and gas operators and service companies to centralise subsurface data management on Azure while maintaining interoperability with the broad OSDU ecosystem of partner applications.
