# Fabric IQ

## Purpose

Fabric IQ is the AI and knowledge-graph enrichment workload within Microsoft Fabric that applies large language model capabilities to structured and unstructured data stored in OneLake. It allows data teams to enrich datasets with entity extraction, semantic embeddings, and Q&A over tabular content without exporting data to a separate AI pipeline, and bridges the Fabric analytical platform with Microsoft AI Foundry capabilities by providing on-platform AI enrichment as a first-class Fabric item type.
