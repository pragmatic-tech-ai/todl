# SharePoint

## Purpose

SharePoint is the cloud-based content management and collaboration platform within Microsoft 365, providing document libraries, intranet sites, team sites, and knowledge portals. It stores and governs the files shared through Teams, hosts Power Pages externally, and underpins M365 Copilot's grounding in enterprise content. SharePoint replaces on-premises SharePoint Server for most new content scenarios and serves as the primary document store accessible via Microsoft Graph.
