# Fabric Data Engineering

## Purpose

Fabric Data Engineering is the Spark-based data transformation and lakehouse authoring workload within Microsoft Fabric, providing notebooks, Spark job definitions, and a Lakehouse item type built on top of OneLake. It replaces Azure Synapse Analytics Spark pools and standalone Azure Databricks for teams already committed to the Fabric platform, offering native Delta Lake tables in OneLake that are shared across other Fabric workloads without copying data.
