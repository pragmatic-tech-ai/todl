# Azure Document Intelligence

## Purpose

Azure Document Intelligence is a machine-learning–based OCR and intelligent document processing service within Foundry Tools that automates structured data extraction from forms, invoices, receipts, contracts, and other semi-structured documents using prebuilt models for common document types and custom models for domain-specific layouts. It exposes REST APIs and SDKs across multiple languages and supports container-based deployment for on-premises or compliance-constrained scenarios. The service is listed as a supported Foundry Tool in US Government regions, making it suitable for federal and regulated workloads.
