# Foundry Local

## Purpose

Foundry Local enables developers to run large language models entirely on-device with no cloud dependency or Azure subscription requirement, using the Foundry Local SDK for Python, C#, JavaScript/TypeScript, and Rust. On Windows it integrates with the Windows ML runtime for hardware-accelerated inference across a broad range of GPU and NPU hardware; a cross-platform package covers macOS and Linux. The primary use cases are on-device AI development workflows, resource-constrained or air-gapped environments, and local integration with models sourced from HuggingFace.
