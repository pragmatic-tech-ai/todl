# Foundry Control Plane

## Purpose

Microsoft Foundry Control Plane is the unified management and governance layer for a Foundry enterprise deployment, centralising fleet management, observability, compliance enforcement, and security monitoring across all AI agents, models, and tools from build through production. It integrates with Microsoft Defender for threat detection, Microsoft Purview for data governance and compliance posture, and Azure Policy for bulk remediation and policy enforcement across projects within a subscription. Key capabilities — including the AI Red Teaming Agent integration, cluster analysis, and continuous evaluation dashboards — are accessed through the Operate section of the Foundry portal.
