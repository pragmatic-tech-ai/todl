# Microsoft Clipchamp

## Purpose

Microsoft Clipchamp is the browser-based video creation and editing tool included in Microsoft 365, designed for non-specialist users to produce training videos, announcements, and marketing clips directly in the browser without desktop video-editing software. It provides templates, text-to-speech narration, screen recording, and auto-generated captions, and is intended as the standard tool for employee-generated video content within the Microsoft 365 ecosystem.
