# Azure Content Understanding

## Purpose

Azure Content Understanding is a generative AI–based Foundry Tool that ingests unstructured content — documents, images, videos, and audio — and produces user-defined structured output through automated field extraction with confidence scores and grounding information. It provides document classification, prebuilt industry analyzers for scenarios such as invoice processing and contract analysis, and is designed as a high-throughput RAG ingestion stage. Content Understanding is generally available in commercial Azure regions but is not available in Azure Government.
