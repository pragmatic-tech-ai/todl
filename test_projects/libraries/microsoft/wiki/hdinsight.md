# HDInsight

## Purpose

Fully managed, full-spectrum, open-source analytics service for enterprises. Supports Hadoop, Spark, Hive, Kafka, HBase, Storm, and Interactive Query — the lift-and-shift Hadoop-ecosystem offering, largely superseded for new work by Synapse and Fabric.
