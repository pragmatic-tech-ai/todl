# Azure Disk Storage

## Purpose

Managed block-level storage volumes for Azure Virtual Machines. Available in Ultra, Premium SSD v2, Premium SSD, Standard SSD, and Standard HDD tiers, with built-in encryption and snapshots. The default persistent-disk primitive for VM workloads.
