# Microsoft Entra ID Governance

## Purpose

Microsoft Entra ID Governance is the identity lifecycle and entitlement management capability in Microsoft Entra ID, providing access reviews, entitlement management (access packages), Privileged Identity Management (just-in-time role activation), and lifecycle workflows for joiners, movers, and leavers. It operationalises the principle of least privilege at scale for large organisations by automating access request and approval flows and scheduling periodic review cycles to clean up stale role assignments without manual audits.
