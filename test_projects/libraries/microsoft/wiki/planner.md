# Planner

## Purpose

Planner is the task and work management application in Microsoft 365 providing Kanban-style boards, task lists, and timeline views for team coordination. It integrates with Teams channels, M365 Groups, and the broader Microsoft To Do task ecosystem, and is designed for lightweight project tracking at the team level without the configuration overhead of full project-management tools. The new Planner in Teams consolidates the earlier Planner and Microsoft Project for the web surfaces into a single interface.
