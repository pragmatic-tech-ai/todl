# Azure Blob Storage

## Purpose

Azure Blob Storage is the massively scalable, unstructured object storage service for cloud-native workloads, data lakes, archives, machine learning, and high-performance computing. It organises objects in containers with hot, cool, cold, and archive access tiers that trade retrieval latency for storage cost. Blob Storage is the foundation for Azure Data Lake Storage Gen2 (via hierarchical namespace) and serves as the primary destination for application-generated files, backups, and analytics staging areas.
