# Microsoft Foundry

## Purpose

Microsoft Foundry is the unified Azure platform-as-a-service for enterprise AI operations, consolidating the previously separate Azure AI Studio, Azure AI Foundry, and Azure AI Services brands under a single resource provider namespace. It provides the infrastructure and management layer covering AI agents, model deployments, and tools together with enterprise-readiness capabilities including distributed tracing, monitoring, evaluations, unified RBAC, private networking, and policy enforcement. Foundry is available in commercial Azure regions globally and in US Government regions (US Gov Virginia, US Gov Arizona), with some preview features limited to commercial regions.
