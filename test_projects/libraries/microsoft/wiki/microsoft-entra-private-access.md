# Microsoft Entra Private Access

## Purpose

Microsoft Entra Private Access is the Zero Trust Network Access (ZTNA) component of Microsoft's Security Service Edge solution, providing identity-aware, per-application tunnelling to private resources hosted on-premises or in any cloud without requiring a traditional VPN client or full-tunnel network connectivity. It replaces VPN-based remote access by enforcing conditional access policies per resource rather than granting broad network segment access, and integrates with Entra ID for single sign-on and multi-factor authentication to each protected application.
