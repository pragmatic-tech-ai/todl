# Microsoft Whiteboard

## Purpose

Microsoft Whiteboard is the infinite-canvas real-time collaboration tool in Microsoft 365, providing a shared visual workspace for distributed teams to sketch diagrams, brainstorm ideas, run retrospectives, and annotate content during meetings. It integrates directly with Microsoft Teams meetings and supports touch, stylus, and pointer input across Surface devices and browsers, serving as the primary replacement for physical whiteboards in hybrid-work scenarios.
