# Microsoft Teams

## Purpose

Microsoft Teams is the Microsoft 365 collaboration hub that combines persistent chat, video meetings, voice calling, file sharing, and app hosting in a single workspace. It extends the earlier Skype for Business platform and is deeply integrated with Exchange Online (calendar, mail), SharePoint Online (files), and Microsoft 365 apps. Teams serves as the primary front-door for agents, bots, and custom tabs built on the Microsoft 365 developer platform.
