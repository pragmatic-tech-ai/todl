# Azure API for FHIR

## Purpose

Managed Fast Healthcare Interoperability Resources (FHIR) service for exchanging clinical data in a standards-compliant format. Provides HIPAA/HITRUST-compliant ingest, storage, and querying for healthcare integrations, superseded for new workloads by the FHIR service inside Azure Health Data Services.
