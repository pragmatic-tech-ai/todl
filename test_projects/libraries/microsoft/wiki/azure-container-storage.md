# Azure Container Storage

## Purpose

Managed persistent-volume service for stateful workloads on Azure Kubernetes Service. Presents Azure Disks, Elastic SAN, and ephemeral NVMe through a Kubernetes-native CSI driver so stateful pods get consistent volume primitives across storage tiers.
